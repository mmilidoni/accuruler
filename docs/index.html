AccuRuler

Measure any element, on any background.

A private, single-purpose browser ruler for Chrome and Firefox.

  • Click-drag to measure any element with live width, height and coordinates.
  • Auto-contrast chrome stays visible on dark pages.
  • Smart labels that never cover what you're measuring.
  • Colors and units (px, mm, cm) you control.
  • No data collection, no ads, no network requests.
